# СельХаб — информационный сайт

Статическая визитка: информация о компании, направления работы и контакты. Только HTML, CSS и изображения. Серверный код, каталог товаров, исходные прайсы, базы данных и клиентские заявки в этот репозиторий не входят.

Для локального просмотра: `python -m http.server 8080 --bind 127.0.0.1` из этой папки. Открыть http://127.0.0.1:8080.

GitHub Pages: ветка main, корневая папка. Домен selhab.ru подключается в настройках Pages после настройки DNS. HTTPS включается после выпуска сертификата GitHub.

## Публичный поиск запчастей

В assets/catalog находятся только пары артикул/название и технические индексы. Поставщики, цены, остатки, исходные прайсы и приватная база приложения не публикуются. Повторяющиеся пары объединяются; цена всегда по запросу, обращение по телефону отдела продаж. Поисковые запросы обрабатываются в браузере, форм сбора контактов, cookies и аналитики нет. Обычные запросы файлов обслуживает GitHub Pages.

Обновление вручную после обновления каталога приложения: запустить scripts/export-public-catalog.py через Python, затем node scripts/check-public-search.cjs, проверить изменения и опубликовать assets/catalog. Экспорт читает активную версию из D:/приложение/catalog-current.json в режиме только чтения. Источники не изменяются. Отдельный сервер не нужен. Каталог не синхронизируется автоматически.
