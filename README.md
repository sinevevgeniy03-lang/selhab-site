# СельХаб — информационный сайт

Статическая визитка: информация о компании, направления работы и контакты. Только HTML, CSS и изображения. Серверный код, каталог товаров, исходные прайсы, базы данных и клиентские заявки в этот репозиторий не входят.

Для локального просмотра: `python -m http.server 8080 --bind 127.0.0.1` из этой папки. Открыть http://127.0.0.1:8080.

GitHub Pages: ветка main, корневая папка. Домен selhab.ru подключается в настройках Pages после настройки DNS. HTTPS включается после выпуска сертификата GitHub.
